## 1. Project Overview

The **ShopSphere E-Commerce Dashboard** case study evaluates commercial performance across key online retail dimensions:
- **Revenue Performance:** Gross Merchandise Value (GMV), Monthly Recurring Revenue (MRR), and Average Order Value (AOV).
- **Customer Acquisition:** Conversion rates across paid acquisition channels and organic search.
- **Cohort Retention:** Repeat customer purchase frequency and customer lifetime value (CLV).
